# Customer Churn Prediction

This project analyzes the impact of **data drift** on a customer churn prediction model.

## Objectives

- Detect data drift in customer behavior
- Compare machine learning models
- Implement a rolling retraining strategy
- Optimize the classification threshold based on business cost

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Key Results

- Best model: Random Forest
- AUC ≈ 0.878
- Optimal threshold: 0.077
- Cost reduction ≈ 36.5%
